MINHA OBRA WEB - VERSAO PARA CELULAR E COMPUTADOR

O painel mobile usa a identidade visual navy e a imagem original da casa.
Ele e uma adaptacao responsiva da interface JavaFX; o celular nao altera nem
substitui o aplicativo Windows. O modelo 3D interativo completo permanece no
aplicativo Windows.

Esta pasta contem uma aplicacao web instalavel (PWA), responsiva e offline
depois do primeiro acesso. Inclui progresso por etapa, orcamento, despesas
e backup manual em arquivo JSON.

LINK DA VERSAO WEB
https://filipe-crl.github.io/minha-obra-web/
Envie este link para quem vai usar pelo celular. O site e publico; nao coloque
dados pessoais ou arquivos da obra no site.

INSTALAR NO CELULAR
Abra o link no navegador do celular.
No Android, use o menu do Chrome e escolha "Instalar app" ou "Adicionar a
tela inicial". No iPhone, use Compartilhar e "Adicionar a Tela de Inicio".

SALVAR E TRANSFERIR DADOS
Os dados ficam no armazenamento do navegador deste aparelho, nao no servidor.
No Windows, abra Configuracoes e escolha "Exportar / enviar para celular".
Guarde o arquivo JSON no OneDrive. No celular, abra a pagina e escolha
"Importar arquivo" para integrar o arquivo. Para mandar as alteracoes de
volta, baixe o backup no celular, coloque-o no OneDrive e use
"Importar dados do celular" nas Configuracoes do Windows.
O arquivo comum transfere etapas, orcamento, despesas, materiais e terreno.
Dados existentes sao mantidos; registros com o mesmo identificador sao
atualizados, despesas/materiais novos sao adicionados e etapas/terreno seguem
o arquivo importado. A sincronizacao ainda e manual: faca uma transferencia
por vez e evite editar a mesma obra em dois aparelhos ao mesmo tempo.
Os arquivos ficam no OneDrive apenas quando voce os envia; nao ha sincronizacao
automatica ou servidor compartilhado nesta versao.

SEGURANCA
Use somente um servico HTTPS de confianca. Nao publique arquivos de backup
com dados pessoais. O arquivo de backup nao e criptografado.
