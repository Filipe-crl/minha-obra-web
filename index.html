Transferir dados da obra

Use o mesmo arquivo JSON para trocar dados com o Minha Obra do Windows. Baixe o arquivo e coloque-o no OneDrive; no outro aparelho, importe-o. O sistema combina lançamentos para evitar apagar despesas e materiais existentes. Faça uma transferência por vez; a sincronização automática ainda não está ativa.

Este site não envia seus dados para um servidor. O navegador guarda as informações somente neste aparelho. Não limpe os dados do navegador sem antes baixar um backup.
